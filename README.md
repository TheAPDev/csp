# WONDERKIN

A premium, cinematic-storybook mobile world for children ages 6–9,
built with React Native + Expo + TypeScript + Supabase.

## Getting Started

```bash
npm install
npx expo start
```

Copy `.env.example` to `.env` and fill in your Supabase project URL
and anon key before running.
